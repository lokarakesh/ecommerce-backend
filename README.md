# E-Commerce Backend Service

Backend service for a multi-vendor e-commerce platform.

## Responsibilities
- REST API development
- Authentication & authorization
- Business logic
- PostgreSQL data modeling
- Redis caching
- Kafka-based async processing

## Tech Stack
- Python
- FastAPI
- PostgreSQL
- Redis
- Kafka

## Architecture
- Modular monolith (microservice-ready)
- API-first design
- Event-driven components

## Status
Phase 0 completed. Database design in progress.
